Message Vault

Combining the cipher with file reading and writing: save secret messages to a file and unlock them with a password. Swap vaults and try to crack them.

Where it falls

Week 2, Secret Codes & Files, Day 10 of 40 in the 2025 curriculum (Building bigger programs).

What students learned

Combine the cipher with file I/O in a password-protected message store.

Concepts

cipher + file reading/writing; password check.

What it asks of students

To finish this project a student has to bring the ideas above together in one working program that runs from start to finish.

The lessons that lead into it

Day 8: Reading Files. Opening files with open() and with, then .read(), .readlines(), and for line in file. File paths, the working folder, and FileNotFoundError. Practice: "Story Reader".

Day 9: Writing & Appending Files. File modes "w" and "a", .write(), newline characters, and why write mode erases old data. Practice: "Diary Logger" adds an entry each run, and "High Score Keeper" remembers scores.

How it is assessed

The project sits inside pre/post assessment pair 2 of 5 for 2025, “Secret Codes & Files” (Week 2 (Days 6–10)). More on the assessments.

Where it goes next

Before this: Project 7, Secret Agent Cipher Lab. After this: Project 9, Trivia Quiz 2.0.
