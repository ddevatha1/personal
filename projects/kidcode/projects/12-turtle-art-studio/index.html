Project 12 of 20 · Year 2 · 2025

Turtle Art Studio

Using the built-in turtle library: turtle objects with methods such as forward(), left(), and begin_fill(). Loops and functions draw spirals, stars, and a draw_flower() function.

Where it falls

Week 6, Libraries & Modules, Day 28 of 40 in the 2025 curriculum (Building bigger programs).

What students learned

Draw with the turtle library using objects, loops and functions.

Concepts

turtle objects and methods (forward(), left(), begin_fill()); loops and functions for spirals/stars; draw_flower().

What it asks of students

To finish this project a student has to bring the ideas above together in one working program that runs from start to finish.

The lessons that lead into it

Day 25: Code Review & Bug Bounty. Swapping projects and hunting bugs with a checklist: clear names, docstrings, functions that do one job, and passing tests. Kind, specific feedback, then refactoring.

Day 26: Modules & the Standard Library. A module is a .py file of ready-made tools and a library is a collection of them. Using import, from ... import, and as. Touring math, random, datetime, string, and collections.

Day 27: Your Own Module & the Docs. Moving helpers like the cipher and ask_number() into kidtools.py and importing them. Reading Python's official documentation: finding a function and reading its signature.

How it is assessed

The project sits inside pre/post assessment pair 5 of 5 for 2025, “Libraries, Modules & Text as Data” (Weeks 6–8 (Days 26–40)). More on the assessments.

Where it goes next

Before this: Project 11, Monster Battle Arena. After this: Project 13, Book Detective.
