Escape the Haunted School

Planning a text adventure called "Escape the Haunted School": sketching the map, listing rooms, items, and win and lose conditions, and drawing a flowchart of the game loop.

Where it falls

Week 8, Capstone & Showcase, Day 36 of 40 in the 2024 curriculum (Python from zero).

What students learned

Plan a text adventure: map, rooms, items, win/lose conditions and a game-loop flowchart.

Concepts

program planning; flowchart of the game loop; rooms/items design.

What it asks of students

To finish this project a student has to bring the ideas above together in one working program that runs from start to finish.

The lessons that lead into it

Day 31: Functions: Reusable Recipes. Defining functions with def, calling them, and why functions keep code tidy (Don't Repeat Yourself). Reading function definitions like recipes. Practice: "Greeting Machine".

Day 32: Parameters & Arguments. Passing information into functions with one or more parameters and default values. Positional and keyword arguments. Practice: "Area Calculator" and "Custom Cheer".

Day 33: return Values. return versus print(), storing a function's result in a variable, and returning True or False. Practice: "Even or Odd?" and "Is It a Palindrome?" as functions.

Day 34: Scope, Docstrings & Testing. Local vs. global variables, docstrings that explain a function, and testing with sample inputs and expected outputs. Lab: "Function Detective" fixes broken functions.

Day 35: Lab: Refactor Day. Rewriting older programs, including "Word Counter" and "Trivia Quiz Show", as clean functions with clear names. Comparing before-and-after code with a partner.

How it is assessed

The project sits inside pre/post assessment pair 4 of 4 for 2024, “Functions & the Haunted School” (Weeks 7–8 (Days 31–40)). More on the assessments.

Where it goes next

Before this: Project 5, Trivia Quiz Show. After this: Project 7, Secret Agent Cipher Lab.
