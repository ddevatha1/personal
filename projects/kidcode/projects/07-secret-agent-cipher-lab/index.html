Secret Agent Cipher Lab

Building encrypt(text, shift) and decrypt(text, shift) with assert tests. Swapping coded messages, then a crack-the-code challenge that tries all 25 shifts.

Where it falls

Week 2, Secret Codes & Files, Day 7 of 40 in the 2025 curriculum (Building bigger programs).

What students learned

Build encrypt/decrypt functions with assert tests and analyze the cipher's weakness.

Concepts

encrypt(text, shift); decrypt(text, shift); assert tests; brute-force (all 25 shifts).

What it asks of students

To finish this project a student has to bring the ideas above together in one working program that runs from start to finish.

The lessons that lead into it

Day 1: Welcome Back & Skills Check-Up. Reviewing Year 1: variables, strings and methods, if statements, loops, lists, dictionaries, and functions. "Python Olympics" relay of short challenges. Setting up the workspace and a tidy KidCode project folder.

Day 2: Functions Power-Up. Default values, keyword arguments such as greet(name="friend"), and returning several values as a tuple. Functions that call other functions. Practice: "Mini Math Toolkit".

Day 3: Scope, Docstrings & Testing. Local vs. global variables, docstrings, and testing with assert: write the test first, then the function. Lab: "Bug- Proof Calculator", where every function passes its own tests.

Day 4: List Power Tools. Nested lists, sorted() and .sort(key=...), enumerate(), zip(), and sets for unique values with set() and .add(). Practice: "Class Leaderboard" sorted by score.

Day 5: List Comprehensions. One-line list builders like [x * 2 for x in numbers], filtering with if, and comprehensions over strings and words. Converting for loops into comprehensions. Practice: "Word Shouter" and "Even Filter".

Day 6: Character Codes & Caesar Shifts. How computers store letters as numbers with ord() and chr(). Shifting letters with % to wrap around the alphabet and looping through strings. Practice: "Letter Shifter".

How it is assessed

The project sits inside pre/post assessment pair 2 of 5 for 2025, “Secret Codes & Files” (Week 2 (Days 6–10)). More on the assessments.
