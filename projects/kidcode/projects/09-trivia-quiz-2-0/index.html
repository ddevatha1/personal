Trivia Quiz 2.0

Upgrading Year 1's quiz: questions loaded from a JSON file, high scores saved to disk, input protected with try/except, and one function per job. Pair review with a checklist.

Where it falls

Week 3, Errors & Data Formats, Day 15 of 40 in the 2025 curriculum (Building bigger programs).

What students learned

Upgrade Year 1's quiz with JSON storage, saved high scores, try/except and one function per job.

Concepts

JSON question bank; persistence; try/except; single-purpose functions; checklist pair review.

What it asks of students

To finish this project a student has to bring the ideas above together in one working program that runs from start to finish.

The lessons that lead into it

Day 11: try/except: When Things Go Wrong. Catching errors with try and except, and common exceptions (ValueError, ZeroDivisionError, KeyError, FileNotFoundError). Reading tracebacks. Practice: "Safe Divider".

Day 12: Bulletproof Input. Validation loops that re-ask until the input is good, else and finally blocks, and a reusable ask_number() function that no silly answer can break.

Day 13: CSV Files. Reading and writing spreadsheet-style .csv files with the csv module, rows as lists, and DictReader for rows as dictionaries. Practice: "Pet Registry".

Day 14: JSON Files. Saving and loading structured data with json.dump() and json.load(). How dictionaries and lists map onto JSON. Practice: "Game Settings" and a "Quiz Question Bank".

How it is assessed

The project sits inside pre/post assessment pair 3 of 5 for 2025, “Errors & Data Formats” (Week 3 (Days 11–15)). More on the assessments.

Where it goes next

Before this: Project 8, Message Vault. After this: Project 10, Virtual Pet Care.
