KidCode: Three Years of Teaching Python

June 2024 – presentFrisco, TexasDeeptanshu Devatha

KidCode is a Python program I started in June 2024 for kids in Frisco. Over three curriculum years it has gone from print("Hello, KidCode!") to object-oriented programs with files and tests, and then to natural-language processing with spaCy. This page is the record of it: what I taught, what students built, how the curriculum changed, and how each claim here can be checked.

The idea that runs through all three years is that each year should end with a problem the next year solves. Year 2 ends with a lesson that feeds its own text-analysis code sentences full of abbreviations like "U.S.A." and logs every way it breaks. Year 3 opens by testing that same code against spaCy.

Assessment

Each unit has a curriculum-aligned pre- and post-assessment. 104 students showed a mean increase from 41.7% to 58.8%, a 17.1-percentage-point gain, and 99 of the 104 improved. This is an observed change; there was no comparison group, so it doesn't show what caused the gain. Details and limits are in the evidence post.

How this was checked

Every number on this page comes from one of three places: the student code itself (students, projects, completions, and what the code contains), the three curriculum documents (class-days, projects, topics), or the pre/post assessment dataset. Each program was run unmodified in an empty folder with scripted input; "working" means it ran to a normal finish. The code was analyzed with Python's own parser rather than by eye. Where something is my own account rather than a record (the June 5 start dates, and the ten communities), I've said so in the table above.

The aggregate data, the methodology, and a script that recomputes every public number are in the KidCode public proof package on GitHub. It contains no student names, no student code, and no individual records.

Student privacy: no student is named anywhere in this archive. The program excerpts are shown without their authors' names, and were chosen by a fixed rule and checked against the full roster so that no student or family name appears, even as a character in a story.
