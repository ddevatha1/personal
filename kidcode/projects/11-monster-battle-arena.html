Project 11: Monster Battle Arena

Curriculum Day 23–24 of 4081 students completed itDeeptanshu Devatha

Monster Battle Arena is Project 11, across Days 23 and 24 of Year 2. A Monster parent class holds name, hit points and attack; FireMonster and WaterMonster inherit from it and override how damage works; a turn-based battle loop uses random damage and type advantages; and winners go into a saved Hall of Fame.

What I taught that week

From the Year 2 curriculum, Week 5: Inheritance & The Arena

Day 21: Inheritance: Parents & Children. Child classes that inherit from a parent class, super().__init__(), and overriding methods. Practice: an Animal parent with Dog and Cat children that each speak() differently.

Day 22: Polymorphism & isinstance(). Treating different objects the same way: looping through a mixed list of animals and calling the same method. Using isinstance() and planning class families on paper.

Day 23–24: Lab: Monster Battle Arena. Project 5. A Monster parent class with name, hp, and attack, plus FireMonster and WaterMonster children. A turn-based battle loop with random damage, type advantages, and a saved "Hall of Fame".

Day 25: Code Review & Bug Bounty. Swapping projects and hunting bugs with a checklist: clear names, docstrings, functions that do one job, and passing tests. Kind, specific feedback, then refactoring.

class Monster:
    def __init__(self, name, hp, attack):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.attack = attack
        self.guarding = False

    def is_alive(self):
        return self.hp > 0

    def roll_damage(self):
        return random.randint(self.attack - 3, self.attack + 3)

    def advantage_against(self, other):
        return 1.0

    def take_damage(self, amount):
        if self.guarding:
            amount = amount // 2
            self.guarding = False
        self.hp = max(0, self.hp - amount)

    def hit(self, other):
        damage = self.roll_damage()
        damage = max(1, int(damage * self.advantage_against(other)))
        other.take_damage(damage)
        print(f"{self.name} hits {other.name} for {damage} damage!")
        return damage

    def __str__(self):
        return f"{self.name} [{self.__class__.__name__}] HP {self.hp}/{self.max_hp}"


class FireMonster(Monster):
    def __init__(self, name, hp, attack):
        super().__init__(name, hp, attack)
        self.element = "fire"

    def advantage_against(self, other):
        if isinstance(other, WaterMonster):
            return 0.6
        return 1.0


class WaterMonster(Monster):
    def __init__(self, name, hp, attack):
        super().__init__(name, hp, attack)
        self.element = "water"

    def advantage_against(self, other):
        if isinstance(other, FireMonster):
            return 1.5
        return 1.0
