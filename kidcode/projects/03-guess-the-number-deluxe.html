Guess the Number Deluxe is Project 3, on Day 20 of Year 1, at the end of the week on loops: while, for and range(), counters, break and continue.

What I taught that week

From the Year 1 curriculum, Week 4: Loops

Day 16: while Loops: Repeat Until. Repeating code with while, loop conditions, and counters. Stopping runaway loops with Thonny's Stop button. Practice: "Countdown Rocket" and "Three Tries Password".

Day 17: for Loops & range(). Looping with for and range() using one, two, and three arguments. Choosing between for (known count) and while (unknown count). Practice: "Times Table Printer".

Day 18: Counting & Looping Through Text. The accumulator pattern for running totals and counters, and looping through every character of a string. Practice: "Vowel Counter", "Palindrome Checker", and "Average Calculator".

Day 19: break, continue & Nested Loops. Leaving a loop early with break, skipping a round with continue, and loops inside loops for grids and patterns. Practice: "Multiplication Grid" and "Star Triangle".

Day 20: Lab: Guess the Number Deluxe. Project 3. Combining while, if/elif/else, random.randint(), and counters into a game with hints, a guess counter, and a play-again option.

What students built

25 students turned in a guessing game. Every one of them has a play-again option; 76% limit the number of guesses; and 56% added "hot / warm / cold" hints on top of higher/lower, working out how far the guess was from the secret number. The median program is 46 lines, roughly three times the Mad Libs median, because it now has a loop inside a loop.

One student's program

This is one real submission, shown as the student wrote it apart from the removed name header. It was chosen by a fixed rule rather than for being the best: it is the submission closest to the project's median length among those that ran cleanly and contain nothing that could identify anyone. Parts are skipped where marked with …

while True:
    rounds += 1
    secret = random.randint(lo, hi)
    guesses = 0
    won = False
    print(f"Round {rounds}: guess the vault number from {lo} to {hi}.")
    while True:
        guess = int(input("Try number: "))
        guesses += 1
        if guess == secret:
            print("The vault clicks open. Cookies for everyone!")
            won = True
            break
        if guess < secret:
            print("Not that low, dear.")
        else:
            print("Not that high, dear.")
        gap = abs(guess - secret)
        if gap <= (hi - lo) // 10:
            print("   You are HOT!")
        elif gap <= (hi - lo) // 4:
            print("   You are warm.")
        else:
            print("   You are cold.")
        if guesses >= max_tries:
            print(f"The vault stayed shut. The number was {secret}.")
            break
    if won:
        print(f"{player} solved it in {guesses} guesses!")
        if best is None or guesses < best:
            best = guesses
            print("New personal best!")
    answer = input("Another round? (yes/no) ").lower()
    if answer != "yes" and answer != "y":
        break

Where it fits

Looking back
