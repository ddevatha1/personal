Project 19: KidBot Brain

Curriculum Day 31–32 of 40118 students completed itDeeptanshu Devatha

KidBot Brain is Project 19, across Days 31 and 32 of Year 3: a rule-based chatbot. Students list intents (greeting, joke, weather), write spaCy Matcher patterns for each, use named entities to pull out the city in "what's the weather in Paris", and add a fallback reply for everything else.

What I taught that week

From the Year 3 curriculum, Week 7: Chatbots & Responsible NLP

Day 31: Lab: KidBot Brain I. Project 6. Designing a rule-based chatbot: listing intents (greeting, joke, weather), writing Matcher patterns for each, and sketching the conversation loop.

Day 32: Lab: KidBot Brain II. Using entities to pull out places and dates so "What's the weather in Paris tomorrow?" gets a pretend forecast. Adding a friendly fallback reply and testing with classmates.

Day 33: How Models Learn. How spaCy's model learned from labeled examples, why training data shapes what a model gets right, and how mistakes and bias appear. Students annotate 20 sentences and compare with the model.

Day 34: Responsible NLP: Bias & Privacy. Fairness, privacy, and knowing when not to use NLP. Class roundtable: "Should a school use NLP to read student essays?" Writing a "Limitations" card for a personal project.

Day 35: Capstone Pitch & Plan. Choosing a project: "Story Explorer", "KidBot Pro", "Privacy Shield Pro", "Time Traveler's News Desk", or an approved original idea. A one-page plan with goals, test texts, and a feature checklist.

What students built

118 students built a KidBot, the most-completed project in the whole program. Every one uses Matcher patterns and reads GPE entities to answer weather questions. They wrote 68 different variants between them.

JOKE_PATTERNS = [

]
BYE_PATTERNS = [
    [{"LOWER": {"IN": ["bye", "goodbye", "later"]}}],
]

matcher.add("GREETING", GREETING_PATTERNS)
matcher.add("JOKE", JOKE_PATTERNS)
matcher.add("WEATHER", WEATHER_PATTERNS)

    def classify(self, text):
        doc = nlp(text)
        matches = matcher(doc)
        if not matches:
            return "UNKNOWN", doc
        match_id, start, end = matches[-1]
        return nlp.vocab.strings[match_id], doc

    def reply(self, text):
        intent, doc = self.classify(text)
        self.history.append((text, intent))
        if intent == "GREETING":
            return f"Hey! I'm {self.name}."
        if intent == "JOKE":
            return random.choice(JOKES)
        if intent == "WEATHER":
            cities = [e.text for e in doc.ents if e.label_ == "GPE"]
            if cities:
                return f"Checking the weather in {cities[0]}... it's lovely!"
            return "Which city?"
        if intent == "BYE":
            return "Goodbye, friend!"
        return "Sorry, I don't know that one yet."

Looking back

A chatbot built from explicit rules is a useful counterweight to the rest of Year 3: students can see exactly why it answers the way it does, which is exactly what they can't see inside the statistical model that finds the entities.
